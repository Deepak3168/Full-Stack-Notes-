# Week 1 — Student Result Calculator

## Objective

Build a simple Python program to calculate a student's result.

The assessment focuses on **Python fundamentals and logical thinking**, not advanced concepts.

## Requirements

### Student Details

Accept:

* Name — `str`
* Age — `int`
* Roll Number — `int`

### Marks

* Accept marks for **6 subjects**.
* Use a **loop** to collect the marks.
* Do **not** create six separate variables for the subjects.
* Maintain a running total while collecting marks.

### Result

Calculate:

* Total marks
* Percentage
* Grade
* Pass/Fail status

Assume each subject is out of `100`.

### Grade

| Percentage | Grade |
| ---------- | ----- |
| 90–100     | A+    |
| 80–89      | A     |
| 70–79      | B     |
| 60–69      | C     |
| 50–59      | D     |
| < 50       | F     |

### Status

* `PASS` if percentage >= 50
* `FAIL` otherwise

Display the student's details and final result clearly.

## Evaluation Focus

Evaluate understanding of:

* Variables and data types
* `input()` and type conversion
* Arithmetic
* Conditions (`if/elif/else`)
* Loops
* Running totals
* Basic logical thinking
* Code structure and clarity

The solution should use **fundamental Python only**. No unnecessary libraries or frameworks.

## Restrictions

**Do not use AI models, ChatGPT, GitHub Copilot, or coding agents to generate the solution.**

The purpose of this assessment is to identify which fundamentals need to be brushed up, **not to give a score**.
